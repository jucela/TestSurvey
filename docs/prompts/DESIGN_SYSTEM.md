Quiero definir e implementar progresivamente un **Design System global para esta aplicación Android de encuesta**, con una interfaz moderna, consistente y adaptable a smartphones y tablets.

Primero, investiga el proyecto siguiendo `AGENTS.md` y `docs/GENERIC_RULES.md`. Revisa también `docs/MOBILE_GUIDELINES.md`, `docs/SPEC_TEMPLATE.md`, la documentación relevante y la interfaz XML existente, incluido el login.

Ayúdame a definir la funcionalidad mediante SDD, siguiendo las plantillas, rutas, etapas y reglas de aprobación establecidas en el repositorio.

El objetivo es establecer una identidad visual compartida, reglas de diseño y componentes reutilizables para las pantallas actuales y futuras.

Considera:

* Colores, tipografía, espaciado y jerarquía visual.
* Botones, campos, selectores, diálogos y componentes propios de encuestas.
* Consistencia visual y reutilización de componentes.
* Adaptación a smartphones, tablets, distintas orientaciones y tamaños de texto.
* Accesibilidad, legibilidad y estados visuales.
* Compatibilidad con la arquitectura y las tecnologías existentes.

La interfaz utiliza XML. No introduzcas Jetpack Compose. Evalúa las tecnologías visuales existentes antes de proponer dependencias nuevas.

**Trabaja primero en la especificación.** Investiga lo comprobable, prepara el borrador de `SPEC.md` usando la plantilla oficial y consulta las decisiones visuales pendientes, proponiendo alternativas cuando sea útil. Haz pocas preguntas por vez.

No inventes decisiones ni amplíes el alcance sin mi aprobación. No modifiques código, temas, estilos, layouts ni dependencias durante esta etapa. No generes `PLAN.md` ni `TASKS.md` hasta que apruebe explícitamente el SPEC.

El Design System deberá convertirse en la referencia visual global para los siguientes features. Si el proyecto aún no dispone de `DESIGN_SYSTEM.md`, evalúa su necesidad y propón cómo documentar allí las reglas visuales aprobadas, sin duplicar las instrucciones existentes.

Empieza por investigar el repositorio y presentar el borrador inicial de la especificación con las decisiones pendientes identificadas.
